# CalorieTrack 🔥

A clean, modern, and responsive Calorie & Macronutrient Tracker web application built with vanilla HTML, CSS, and JavaScript. 

No backend required — all user data, meals, nutrition goals, and water intake are persistently stored directly in the browser's `localStorage`.

---

## ✨ Features

- **Daily Calorie Budget Equation**: `Daily Goal - Consumed = Remaining` with real-time dynamic progress indicators.
- **Macronutrient Tracking**: Real-time progress bars for Protein, Carbohydrates, and Fat with grams consumed vs. goals.
- **Meal Categorization**: Log and organize foods into Breakfast, Lunch, Dinner, and Snacks with subtotals.
- **Quick Calorie Entry**: Instant buttons to log `+50`, `+100`, `+200`, or `+500` kcal without full forms.
- **Pre-populated Presets**: 13+ quick-select common foods (Scrambled Eggs, Oatmeal, Grilled Chicken, Banana, Greek Yogurt, etc.).
- **Interactive Hydration Tracker**: Track daily water intake cup by cup.
- **7-Day Trend Visualizer**: Built-in HTML5 Canvas weekly bar chart comparing daily intake against targets.
- **Data Backup & Restore**: Export and import complete logs in JSON format anytime.
- **100% Vanilla**: Zero frameworks, zero CSS variables, zero Tailwind, zero external dependencies.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser. No installation or web server required!

```bash
# Clone the repository
git clone https://github.com/SimonUI/calorie-tracker.git

# Open the project
cd calorie-tracker
start index.html
```

## 🛠️ Tech Stack

- **HTML5**: Semantic UI, accessible dialogs, and native date inputs.
- **CSS3**: Pure CSS styling, Flexbox, and CSS Grid layouts.
- **JavaScript (ES6+)**: Event handling, DOM manipulation, HTML5 Canvas API, and `localStorage` persistence.
